## 🎬 SQL.SSL REEL QUALITY ADD-ON — इसे Master Prompt File के साथ हर बार लागू करो

हर Reel पिछली सफल Reel जैसी cinematic, scene-specific और high-quality बनाओ। Generic hacker posters, random dark backgrounds, abstract code या एक जैसी images बिल्कुल मत बनाओ। पहले live news → 90–120 शब्दों की script → voice duration → 18–25 visual moments → हर moment के लिए अलग exact scene → animation → final video का क्रम हमेशा follow करो।

**VOICE RULE — सबसे महत्वपूर्ण:**
Voice की शुरुआत सीधे news की बात से हो। "रुकिए", "रुकिए—", "सुनिए", "ध्यान दीजिए" या कोई generic intro बिल्कुल नहीं होना चाहिए। पहली line direct shocking fact या direct warning हो, जैसे: "बेंगलुरु में एक crypto-investment scam ने एक व्यक्ति से ₹93.58 लाख ठग लिए।" Voice deep, heavy, serious, natural और conversational male Hindi हो; शुरुआत में कोई greeting या filler नहीं। आखिरी line में @sql.ssl Follow CTA जरूर हो।

**VISUAL QUALITY RULE:**
हर image voice की exact line को visually दिखाए। Script को 18–25 छोटे moments में तोड़ो और हर moment के लिए पहले यह लिखो: (1) voice line, (2) exact scene, (3) क्या नहीं दिखाना। फिर image generate करो।

हर visual में यह fixed style रखो:
"Cinematic cyberpunk anime style, 2D digital painting, thin glowing outlines, neon cyan/red/gold lighting, dramatic realistic composition, 9:16 vertical aspect ratio, main subject centered, mobile-safe padding, detailed environment, strong depth and cinematic contrast."

**SCENE ACCURACY:**
- WhatsApp scam बोले तो असली WhatsApp-जैसा chat/investment group और suspicious message दिखाओ।
- Telegram बोले तो Telegram-जैसा group/channel context दिखाओ।
- Bengaluru/India बोले तो Bengaluru skyline, Indian victim, Indian rupee और Indian setting दिखाओ।
- Fake profit बोले तो fabricated trading dashboard और artificial green returns दिखाओ।
- Repeated transfers बोले तो phone, bank-transfer trail और draining balance दिखाओ।
- Mule accounts बोले तो connected bank-account network और investigator evidence दिखाओ।
- APK बोले तो phone पर untrusted APK install warning दिखाओ।
- OTP बोले तो six-digit OTP interception/blocking दिखाओ।
- Crypto wallet बोले तो rupee-to-crypto money trail दिखाओ।
- Safety tip बोले तो वही exact action दिखाओ: APK reject, OTP lock, official app verification आदि।
- हर scene अलग हो; एक ही hacker या same composition repeat मत करो।

**BRANDING RULE:**
हर image में @sql.ssl / SQL.SSL branding naturally embedded हो—phone corner, monitor signature, jacket emblem, code line या environment detail में। Thumbnail/closing frame में attached @sql.ssl profile logo को identity reference की तरह use करो; fake logo या generic logo मत बनाओ। Thumbnail में login screen या hacked-account screen नहीं होना चाहिए।

**TEXT OVERLAY RULE:**
हर image के center/middle safe zone में उसी moment की 5–8 शब्दों की bold Hindi key line overlay करो। Bottom 20% या top 10% में text मत रखो। White bold text, dark outline/shadow, readable size, high contrast। Devanagari text सही render होना चाहिए—boxes, broken glyphs या unreadable text दिखे तो frame regenerate/fix करो। English technical terms को जरूरत हो तो Hindi script में लिखो: Crypto = क्रिप्टो, OTP = ओटीपी, APK = एपीके।

**VIDEO RULE:**
हर image पर subtle Ken Burns zoom/pan लगाओ; plain slideshow नहीं। Voice की exact measured duration के बराबर final video रखो। Voice dominant हो, BGM subtle dark cyberpunk electronic instrumental हो, fade-in/fade-out के साथ। Final export 1080×1920 vertical H.264 MP4 में हो।

## STEP 3B — [NEW] Ken Burns Animation — हर इमेज को Motion दो

> 🎬 **यह step क्यों ज़रूरी है:**
> Static images का slideshow Instagram algorithm detect कर लेता है और उसे कम distribute करता है। Ken Burns effect (slow zoom/pan) हर image को एक real motion video जैसा बना देता है — **watch time बढ़ता है, algorithm ज़्यादा push करता है।**

```bash
#!/bin/bash

# ── Ken Burns Effect — हर इमेज पर slow zoom या pan लगाओ ───────────────────────
NUM_IMAGES=20  # जितनी इमेज बनाई हों
IMAGE_DURATION=2.0  # STEP 2C से लिया हुआ value यहाँ डालो

# FPS और frames calculate करो
FPS=30
FRAMES=$(echo "$IMAGE_DURATION * $FPS" | bc | awk '{printf "%d", $1}')

# हर इमेज पर Ken Burns apply करो — animated clip बनाओ
for i in $(seq 1 $NUM_IMAGES); do

  # Alternate: zoom-in और zoom-out + slight pan — variety के लिए
  if [ $(( i % 3 )) -eq 0 ]; then
    # Zoom In + Slight Left Pan
    ZOOM_FILTER="zoompan=z='zoom+0.0015':x='iw/2-(iw/zoom/2)-((iw/zoom/2)*0.03*on/$FRAMES)':y='ih/2-(ih/zoom/2)':d=$FRAMES:s=1080x1920:fps=$FPS"
  elif [ $(( i % 3 )) -eq 1 ]; then
    # Zoom Out (start zoomed, pull back)
    ZOOM_FILTER="zoompan=z='if(lte(zoom,1.0),1.5,max(1.001,zoom-0.0015))':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=$FRAMES:s=1080x1920:fps=$FPS"
  else
    # Zoom In + Slight Right Pan
    ZOOM_FILTER="zoompan=z='zoom+0.0015':x='iw/2-(iw/zoom/2)+((iw/zoom/2)*0.03*on/$FRAMES)':y='ih/2-(ih/zoom/2)':d=$FRAMES:s=1080x1920:fps=$FPS"
  fi

  ffmpeg -y -loop 1 -i /home/ubuntu/image_${i}.png \
    -vf "$ZOOM_FILTER" \
    -t $IMAGE_DURATION \
    -c:v libx264 -pix_fmt yuv420p \
    /home/ubuntu/clip_${i}.mp4

  echo "Clip $i animated ✓"
done

echo "सभी clips animated — Ken Burns complete!"

# ── सभी animated clips को एक list में लिखो ───────────────────────────────────
> /home/ubuntu/clips.txt
for i in $(seq 1 $NUM_IMAGES); do
  echo "file '/home/ubuntu/clip_${i}.mp4'" >> /home/ubuntu/clips.txt
done
echo "clips.txt तैयार ✓"

# ── सभी clips को एक video में जोड़ो (बिना audio) ─────────────────────────────
ffmpeg -y -f concat -safe 0 -i /home/ubuntu/clips.txt \
  -c:v libx264 -pix_fmt yuv420p \
  /home/ubuntu/video_no_audio.mp4

echo "Animated video (बिना audio) तैयार ✓"
```

> **नोट:** यह STEP पूरा होने के बाद `/home/ubuntu/video_no_audio.mp4` तैयार होगा। STEP 6 में इसी file को use करो।

## STEP 6 — वीडियो असेंबली (Voice Over Duration से Match)

> **वीडियो की कुल लंबाई = $VOICE_DURATION — कोई fixed -t 20 नहीं।**
> **Note:** STEP 3B में video_no_audio.mp4 पहले से बन चुकी है। यहाँ सिर्फ audio mix करना है।

```bash
#!/bin/bash

# ── Voice Over Duration लो ────────────────────────────────────────────────────
VOICE_DURATION=$(ffprobe -v error -show_entries format=duration \
  -of default=noprint_wrappers=1:nokey=1 /home/ubuntu/narration.wav)
echo "Voice Over Duration: $VOICE_DURATION sec"

# ── Audio Mix करें — Final Video बनाएँ ───────────────────────────────────────
# Voice Over Volume: 2.2 (भारी, शक्तिशाली आवाज़ — clearly dominant)
# BGM Volume: 0.30 (background में subtle — voice को दबाए नहीं, energy दे)
ffmpeg -y \
  -i /home/ubuntu/video_no_audio.mp4 \
  -i /home/ubuntu/narration.wav \
  -i /home/ubuntu/bgm.wav \
  -filter_complex \
    "[1:a]volume=2.2[a1]; \
     [2:a]volume=0.30,afade=t=in:ss=0:d=3,afade=t=out:st=$(echo "$VOICE_DURATION - 3" | bc):d=3[a2]; \
     [a1][a2]amix=inputs=2:duration=first[aout]" \
  -map 0:v \
  -map "[aout]" \
  -c:v copy \
  -c:a aac \
  -t $VOICE_DURATION \
  /home/ubuntu/cybersecurity_reel.mp4

echo "Final Video तैयार!"
echo "Video Duration = Voice Over Duration = $VOICE_DURATION seconds"
```

> **Volume नोट:**
> - `Voice Over (SQL 💉): 2.2` — आवाज़ dominant और साफ — viewer clearly समझे
> - `BGM: 0.30` — नया rhythmic BGM सिर्फ atmosphere और energy दे — voice को न दबाए
> - BGM में `afade=in` और `afade=out` — smooth start और end, कोई abrupt cut नहीं
